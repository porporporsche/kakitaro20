# 栗太郎電鉄20！

日本全国146都市と海外38都市をサイコロと飛行機でめぐり、物件の購入・増資・M&AでCPUの山岡社長と総資産を競う、オリジナルの鉄道すごろくゲームです。
スマホ・PCのブラウザでそのまま遊べます（インストール不要、`index.html` 1ファイルで動作）。

## 遊び方
- プレイ年数は 3年・5年・10年、または 1〜99年の自由入力から選べます。
- サイコロの目で行けるマスが光り、行き先を選べます（どの方向へも、引き返してもOK）。
- 空港のある町からは飛行機で国内・海外へ。地図左上の「世界」に海外38都市があります。
- 自分の物件は増資（価格の半額）で収益が1回ごとに70%アップ（最大★3）。
- 総資産1000億円以上で「1000億クラブ」：各都市の隠し資産（数十億〜数百億円）を購入でき、すべて買い占めるとその都市を支配（収益3倍・相手は購入不可）。札の上限なし、プライベートジェットでどこへでも無料、投資銀行家でどの都市の資産も遠隔で購入・増資。
- 支配都市の収益は町全体でベースの7倍。支配都市でゴールすると賞金1000倍。
- 総資産2兆円以上でVIP資産（500億〜2000億円・収益率30〜50%）を購入可能。
- 「💡 投資提案」で、投資額と増える年収益（利回り・回収年数）から有望な購入・増資案件を確認できます。
- 総資産50兆円以上でExecutive資産（5000億〜25兆円・収益率35〜75%）を購入可能。買い占めた都市は収益がさらに10倍。
- 総資産50兆円以上のプレイヤーだけが入れる「エグゼクティブ環状エリア」（山手線などの駅名の40都市）。
- 総資産10京円以上のプレイヤーだけが入れる「世界の国々エリア」（実在する50か国）。各国の資産をこれまでと同じルールで購入できます。
- 一覧や物件の画面は、右上の✕・下に固定されたボタン・背景タップのどれでも閉じられます。
- 総資産1京円以上のプレイヤーは目的地の賞金が1000万倍。
- 目的地に一番乗りすると賞金。駅に止まると物件を買えます。町の物件をすべて買うと「買い占め」で収益2倍。
- 相手の物件は M&A（1.5倍、買い占め中の町は2倍）で買収できます。
- 6月に「渋柿ガラス」が登場。ついてくると柿を渋くしてお金を減らします。
- セーブデータは5つまで。進行は月ごとに、選んだスロットへ自動保存されます（以前のセーブは自動でスロットへ移ります）。
- BGM・効果音はオリジナル曲をブラウザ内で生成しています（画面右上の「♪」で切替）。季節ごとに曲調が変わり、渋柿ガラスがつくと専用の曲になります。

## GitHub Pages で公開する手順
1. GitHub で新しいリポジトリを作成（例: `kakitaro-dentetsu-20`、Public）。
2. このフォルダの中身（`index.html` / `README.md` / `.nojekyll`）をリポジトリの直下にアップロードしてコミット。
3. リポジトリの **Settings → Pages** を開き、**Source: Deploy from a branch**、**Branch: `main` / `(root)`** を選んで Save。
4. 1〜2分後、`https://<ユーザー名>.github.io/kakitaro-dentetsu-20/` で遊べるようになります。

コマンドで行う場合:
```bash
git init && git add . && git commit -m "栗太郎電鉄20！ 初回公開"
git branch -M main
git remote add origin https://github.com/<ユーザー名>/kakitaro-dentetsu-20.git
git push -u origin main
```
